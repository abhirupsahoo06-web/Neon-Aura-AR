# 🌌 Neon Aura AR

✨ *Control neon energy with your hands.*

Neon Aura AR is a futuristic, browser-based augmented reality experience that uses real-time hand tracking to create interactive neon visuals, particles, and sound. Built with cutting-edge web technologies, it turns your webcam into a gesture-controlled AR playground.

---

## 🚀 Features

* 🖐️ Real-time hand tracking (up to 2 hands)
* 🤏 Gesture detection (pinch, open hand, spread)
* ✨ Neon particle system & glowing trails
* ⚡ Shockwaves, ripples & lightning effects
* 🌌 Matrix-style animated background
* 🌈 Dynamic themes (Rainbow, Cyberpunk, Lava, Ocean, Galaxy)
* 🎧 Reactive sound system (ambient hum + zap effects)
* 📊 Live HUD (FPS, gesture, hand count, spread %)

---

## 🛠️ Technologies Used

* HTML5, CSS3, JavaScript
* MediaPipe Hands (AI hand tracking)
* Web Audio API
* Canvas (2D rendering)

---

## 🎮 How to Use

1. Open the project in your browser
2. Allow camera access 📷
3. Click **“Enter Experience”**
4. Move your hands in front of the camera

### 🧠 Gestures:

* 🤏 Pinch → Creates shockwaves
* ✋ Open hand → Controls spread
* ✌️ Two hands → Generates energy beams & effects
